# **App Name**: NP Manager

## Core Features:

- User Authentication: Secure user login for different roles (General Manager, Branch Manager, Staff).
- Role-Based Access Control: Control panel access based on user role (General Manager sees all branches, Branch Manager sees only their branch, Staff see only limited information for their usage).
- Shift Management: Create and manage work shifts for staff.
- Inventory Tracking: Track the current stock levels of each product, where Branch Managers will be responsible for the tracking of stock.
- Personal Report Generation: Allow employees to check their shifts, and overtime using a dedicated report. Include the ability to check lateness in arrival to work
- AI-Driven Task Prioritization: An AI "tool" to dynamically prioritize tasks from the checklists based on urgency, due date, and importance, helping the restaurant staff focus on what matters most.  Tasks should be scored on various metadata in order to correctly classify priorities.
- Real-Time Task Completion Logging: Log the timestamps when an element is marked as complete in any checklist.

## Style Guidelines:

- Primary color: Saturated red (#E63946), inspired by the brand's association with 'Sample,' conveying energy and appetite.
- Background color: Light gray (#F4F3F6), a desaturated tint of the primary, providing a clean and neutral backdrop.
- Accent color: Analogous orange (#F4A261), offering a vibrant contrast for calls to action and important elements.
- Headline font: 'Poppins', a geometric sans-serif, chosen for its contemporary and fashionable style to draw attention to important headlines.
- Body font: 'PT Sans', a humanist sans-serif, chosen for its readability and modern aesthetic to allow ease of use of the app
- Use simple, line-based icons for easy recognition and a modern look.
- Implement a clean, card-based layout for data presentation.
